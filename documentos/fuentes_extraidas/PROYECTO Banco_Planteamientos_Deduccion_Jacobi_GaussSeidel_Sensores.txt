Métodos Numéricos – Jacobi y Gauss-Seidel con sensores Arduino Uno
Objetivo: que los estudiantes construyan las ecuaciones algebraicas a partir de cada situación de ingeniería, formen A·x=b y resuelvan el sistema con Jacobi y Gauss-Seidel.
Orientaciones para los estudiantes
Defina las incógnitas, unidades y significado físico.
Identifique qué mide cada sensor y cómo convertir la lectura ADC o digital a una magnitud útil.
Deduza las ecuaciones a partir de balances, equilibrio, calibración, continuidad o relaciones del proceso.
Organice las ecuaciones como A·x=b.
Verifique si la matriz es diagonalmente dominante.
Use x^(0)=0, tolerancia 0.001 y máximo 100 iteraciones, salvo que el docente indique otra condición.
Resuelva con Jacobi y Gauss-Seidel.
Calcule el error entre iteraciones y el residuo r=A·x−b.
Compare convergencia, iteraciones y significado físico.
Formato mínimo de entrega
Planteamiento → variables → conversión de sensores → ecuaciones → A y b → dominancia diagonal → Jacobi → Gauss-Seidel → tablas → residuo → gráfica → conclusión.
1. Placa térmica con LM35
Planteamiento: Tres LM35 están ubicados en tres nodos internos de una placa. Las lecturas de temperatura de frontera y de una fuente térmica se toman simultáneamente. El balance de energía de cada nodo considera su propia temperatura y el intercambio con los nodos vecinos. Deduzca tres ecuaciones para T1,T2,T3.
Sensor(es): LM35 analógico
Pista de modelado: Convierta ADC→voltaje→°C. Explique qué lecturas forman b y cuáles parámetros permanecen en A.
El grupo debe entregar: las ecuaciones deducidas, A, b, las fórmulas iterativas, las tablas de Jacobi y Gauss-Seidel, la verificación y una graphics.

Advertencia metodológica
Los sensores no producen ecuaciones automáticamente. El modelo físico, la calibración y las condiciones del problema determinan la matriz A y el vector b. Las lecturas deben convertirse a unidades coherentes y documentarse.
