Problemas de ingeniería con sensores: Jacobi y Gauss-Jordan
Guía para estudiantes – Métodos Numéricos
Objetivo: deducir sistemas de ecuaciones a partir de problemas de ingeniería con sensores analógicos y digitales, y resolverlos mediante Jacobi y Gauss-Jordan.
Indicaciones generales
Defina las variables desconocidas y sus unidades.
Explique qué mide cada sensor y cómo se convierte la lectura.
Deduza las ecuaciones desde balances, calibración, equilibrio o relaciones del proceso.
Construya A y b.
Verifique dominancia diagonal para Jacobi.
Use x^(0)=0 y tolerancia 0.001 para Jacobi.
Resuelva también mediante Gauss-Jordan y compare los resultados.
Calcule el residuo r=A·x−b y presente una gráfica de convergencia.
1. Balance térmico con tres LM35
Planteamiento: Tres LM35 se colocan en tres nodos de una placa. El modelo de balance térmico discretizado establece que cada nodo intercambia calor con sus vecinos. Las lecturas de frontera o fuentes se convierten en b. Deduza el sistema para T1,T2,T3 y resuélvalo con Jacobi y Gauss-Jordan.
Sensor(es): LM35 analógico
Datos de trabajo para validar el modelo: A: [10 −1 2; −1 11 −1; 2 −1 10], b: [18,20,27]
Tarea: deduzca el sistema con sus propias palabras, explique la correspondencia entre sensores, A y b, resuelva por Jacobi y Gauss-Jordan, y compare el residuo.
